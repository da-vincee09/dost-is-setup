# 💰 Ilocos Sur Refund and Collection Monitoring System

A modern web-based **Refund and Collection Monitoring System** designed to streamline the tracking, management, and reporting of refund and collection records. The application provides a centralized platform for monitoring transactions, generating reports, and maintaining accurate financial records through an intuitive interface powered by **Supabase** and **Node.js**.

---

## 📖 Overview

The **Ilocos Sur Refund and Collection Monitoring System** is a full-stack web application that combines a responsive frontend with a cloud-based backend to simplify refund and collection management.

The project includes:

- 🌐 A responsive frontend built with HTML, CSS, and JavaScript
- ☁️ Supabase for authentication, database, and storage
- 🟢 Node.js for development, build, and utility scripts
- 📊 Data import, reporting, and archival tools
- 🚀 Flexible deployment for static hosting or Node.js environments

The application is designed to provide an efficient and organized workflow for managing refund and collection records while ensuring secure data access and reliable reporting.
